# App environments

T3 creates tasks, chooses hosts, and creates worktrees. This tool only discovers, prepares, starts, inspects, and stops an app environment.

Claims are exclusive and nonce-owned. Host port leases cover clones for the same OS user; strict binds catch other collisions. Stop through the verified control socket and exact subprocess handles. Never kill a saved PID or remove an uncertain stale claim automatically.

Cleanup waits for startup resource acquisition. Test concurrent claims, disjoint ports, startup cancellation, and isolated app data. Keep full two-stack verification separate from fast merge tests.
